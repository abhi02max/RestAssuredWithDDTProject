# Rest Assured Data-Driven API Testing

A Java API-automation project using Rest Assured and external test data to execute repeatable REST API validations.

## Technology

Java · Rest Assured · TestNG · Maven

## Demonstrated skills

- HTTP request construction and response validation
- Data-driven test execution
- Positive and negative API scenarios
- Status-code and payload assertions
- Reusable test organisation

## Run

```bash
mvn clean test
```

Review the test configuration before execution and keep credentials outside source control.
